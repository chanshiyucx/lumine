# 地图组件代码质量优化方案

- 日期：2026-09-30
- 状态：已实施；生产构建的数据收集受既有媒体 manifest 版本阻塞
- 范围：`web/components/map`、地图共享类型与聚类配置

## 目标与约束

整理地图模块的职责、命名、类型和计算依赖，保持现有页面呈现与交互。保留地图样式、动画参数、卡片布局、缩略图顺序、悬浮延迟、触摸和键盘处理、图片加载策略、初始定位、范围切换与重试行为。不增加测试文件，不引入通用控制器、Context、额外状态库或全局缓存。

## 聚类与固定状态

固定单个项目时记录其 `album` 或 `photo` 类别与 key。固定终端照片聚类时保留原 marker key、完整成员和中心坐标；索引排除这些成员后，原聚类可能不再存在，因此不能只保存 cluster ID。

相册索引只响应相册数据和固定相册 key；照片索引只响应照片数据及本层的固定照片或聚类成员。对方图层的固定状态变化不重建本层索引。索引不直接依赖整个固定状态对象。

继续在构建索引前移除固定成员，保持聚类数量与中心位置。不能改成仅在渲染时隐藏固定成员。

## 模块划分

| 文件                                           | 职责                                         |
| ---------------------------------------------- | -------------------------------------------- |
| `web/lib/map-types.ts`                         | 服务端与客户端共享的地图项目、封面和位置类型 |
| `web/lib/map-items.ts`                         | 保留 `server-only`，负责地图数据读取与组装   |
| `web/components/map/lib/map-clustering.ts`     | 聚类索引创建、标记数据转换及固定状态契约     |
| `web/components/map/hooks/use-map-clusters.ts` | 独立索引依赖、视口查询与平铺标记数据派生     |
| `web/components/map/map-markers.tsx`           | 平铺标记渲染、事件绑定与现有标记外观         |
| `web/components/map/photo-map.tsx`             | 地图实例、加载重试、镜头控制和选择操作       |
| `web/components/map/lib/map-viewport.ts`       | 视口类型、坐标限制、overscan 和图片加载策略  |

Hook 不接收地图 ref 或状态 setter，不返回镜头控制回调或 JSX。交互操作留在地图容器，由标记渲染层绑定。保留现有平铺 UI 文件和三个独立的预览卡片，不为少量代码再拆多个 hook。

## 计算生命周期

视口与本层索引变化时查询标记并准备成员、展开 zoom 和稳定 key。相册聚类仍只读取最多六个预览成员；照片聚类仍读取全部成员，并保持 `getLeaves` 顺序。

完整照片成员读取移出 JSX，放进明确的 memo 派生阶段。日期范围和相机汇总仍在照片预览卡片挂载后调用 `getPhotoSummary`，不提前汇总所有视口内聚类。Radix 预览内容继续按现有方式挂载，不增加 `forceMount`。

本轮不增加按 cluster ID 的额外缓存，也不引入统计 `map/reduce`。如后续性能测量确认存在明显成本，再单独评估按需读取或预聚合，并验证时间比较、同时间成员选择、相机一致性与日期文案不变。

## 类型、命名与组件身份

- 相册与照片聚类预览分别接收只读的对应项目集合，去掉照片卡片中重复的类别筛选。
- Supercluster 聚类成员的非空保证只在结果转换处集中表达，不散布类型断言、占位封面或可选链。
- 聚类标记区分可展开聚类与支持固定的终端照片聚类，回调与模式绑定。当前相册聚类上限为 15，zoom 16 已拆成单个项目，不增加不可达的终端相册分支。
- `map-selection.ts` 改为 `map-clustering.ts`；动态加载变量改为 `LazyPhotoMap`；`ClusterMarker` 改为 `MapClusterMarker`；`MAX_CLUSTER_ZOOM` 改为 `ALBUM_CLUSTER_MAX_ZOOM`。
- 保留普通与固定标记的平铺列表、列表顺序、key 规则和组件类型，不增加标记外层 DOM。
- 保留返回原生 button 的触发器辅助函数，避免改变 Radix `asChild` 的事件、属性与 ref 透传。
- 现有 `import type` 已被擦除，拆分共享类型用于明确职责，并非修复服务端代码进入客户端的问题。

## 实施顺序

1. 共享类型与命名整理。
2. 固定状态分类及索引依赖隔离。
