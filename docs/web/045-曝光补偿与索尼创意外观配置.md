# 曝光补偿与索尼创意外观配置

日期：2026-09-27

## 范围

新增曝光补偿和 Sony Creative Look 配置。焦平面分辨率、数字变焦和其他厂商字段不在本次范围内。manifest 仍为 v3，增加可选字段；旧条目可以被新 Web 读取，但需要重建元数据才能获得新增值。

## 数据契约

`camera.exposureBiasValue`：有限数值，单位 EV，来自标准 EXIF ExposureBiasValue，保留两位小数；0 和负值有效，缺失时省略。

`camera.creativeLook`：有可读取的 Sony 创意外观名称时保存，包含以下字段：

| 字段           | 类型／范围     | 含义                                                                                                |
| -------------- | -------------- | --------------------------------------------------------------------------------------------------- |
| name           | string         | 相机外观名称；Standard、Portrait、Neutral、Vivid、Sepia 归一为 ST、PT、NT、VV、SE，其余有效名称保留 |
| contrast       | integer，−9～9 | 对比度                                                                                              |
| highlights     | integer，−9～9 | 高光                                                                                                |
| shadows        | integer，−9～9 | 阴影                                                                                                |
| fade           | integer，0～9  | 褪色                                                                                                |
| saturation     | integer，−9～9 | 饱和度                                                                                              |
| sharpness      | integer，0～9  | 锐度档位                                                                                            |
| sharpnessRange | integer，1～5  | 锐度范围                                                                                            |
| clarity        | integer，0～9  | 清晰度                                                                                              |

名称必需，其他字段均可缺省。零值保留，缺失或非法数值省略，不用默认值补齐。

## 提取边界

pipeline 直接解析 SONY DSC／SONY CAM MakerNote 的主 IFD，遵循源 TIFF 字节序和绝对偏移，读取外观字符串及八个数值标签。仅处理 Sony 品牌且具有支持的头部的源图，损坏或不支持的数据安全省略。不依赖运行时 ExifTool，不解析完整厂商数据。

这些值来自机内外观配置，不回退到标准 EXIF Contrast／Saturation／Sharpness 的三档摘要，也不使用 Lightroom XMP 后期参数。锐度 4 是档位，不是相对增加 +4。

## 展示

- Shooting Settings 依次显示 Shooting Mode（Exposure Program）、Exposure Mode 和 Exposure Compensation，例如 +0.7 EV、0 EV、−0.7 EV，不使用折叠详情。
- 信息面板依次展示 Photo Information、Capture Parameters、Creative Look（有数据时）、Histogram、Equipment、Shooting Settings 和 Location。有经纬度时，地点、坐标和地图归入独立 Location 分区；无经纬度时，仅在 Photo Information 中显示 Location 字段，不显示独立分区。
- Capture Parameters 焦距卡片显示实际焦距，缺失时回退到等效焦距；Equipment 仅在两者都有记录且不相同时补充 35mm Equivalent，避免重复。
- 默认面板移除 Brightness，仍保留其数据提取。Sensing Method 已从 pipeline 和数据契约中移除，不提供旧字段兼容，使用新 Web 前需同步重新生成的 manifest。
- 地图在当前 Viewer 首次遇到有经纬度的照片且面板活动时创建；无坐标时隐藏整个 Location 分区并保留实例，切回有坐标照片时复用，退出预览后卸载。
- 有创意外观配置时，显示 Creative Look 分区；名称独占一行，其余八项按相机顺序采用两列四行布局。
- 对比度、高光、阴影、饱和度的正值带加号；褪色、锐度、锐度范围、清晰度显示档位数值。
- 缺失设置不显示行，未记录配置的照片不显示分区。

## 验证

读取图库全部 459 张源照片，包含 Sony α6700 452 张、iPhone 13 Pro 6 张和 iPhone 11 Pro Max 1 张：

- 曝光补偿在 459 张中都有记录。
- Sony 外观名称和八项数值在 446 张中完整存在；包含非零高光、阴影和清晰度。
- 新 Rust 解析结果与独立 ExifTool 读取逐张、逐字段比较，446 份配置全部一致。
- 11 张真实 JPEG／HIF／HEIC 样本在隔离目录通过完整 pipeline 和 Web v3 schema，并验证零值、缺失值、有符号调节和锐度档位的展示。
- MakerNote 解析测试覆盖大小端、内联名称、绝对偏移、负数和零值、非法类型／范围、外来及截断数据。

## 刷新已有图库

备份输出目录的 manifest.json 后移走该文件，再运行现有 pipeline。可用图片和缩略图会复用，只重新提取照片条目；state.json 不需要删除。
