# 样式优化

## 目标

1. 瀑布流的每张图片，如果有等效焦距、光圈、快门、ISO，需要在 hover 时显示。
2. 当前站点只有 Rose Pine dark 主题，`components/photo` 下的颜色实现需要全部收敛到主题变量，不能继续混用 `white/black/amber` 这类硬编码色。

## 已实施

### 1. 首页瀑布流 hover 信息补全

- [photo-card.tsx](/Users/xin/Developer/lumine/components/photo/photo-card.tsx) 现在会复用 [viewer-metadata.ts](/Users/xin/Developer/lumine/components/photo/lib/viewer-metadata.ts) 中已有的拍摄参数格式化逻辑。
- 新增 `getAvailableCaptureSettings(photo)`，只提取有值的参数项，避免首页 hover 层出现 `Not available`。
- 首页 hover 层新增 2 列参数网格，支持展示：
  - `35mm equivalent / focal length`
  - `aperture`
  - `shutter`
  - `ISO`
- 参数卡片组件抽成 [photo-capture-setting-chip.tsx](/Users/xin/Developer/lumine/components/photo/photo-capture-setting-chip.tsx)，避免首页 hover 和右侧信息栏重复维护图标映射与样式结构。

### 2. 颜色实现收敛到 Rose Pine 主题变量

- `components/photo` 目录中原有的 `bg-black`、`text-white`、`border-white`、`amber` 等写法已全部移除。
- 统一改为使用主题 token 对应的 Tailwind 颜色类：
  - `base`
  - `surface`
  - `overlay`
  - `muted`
  - `subtle`
  - `text`
  - `gold`
- 覆盖范围包括：
  - [photo-viewer.tsx](/Users/xin/Developer/lumine/components/photo/photo-viewer.tsx) 的遮罩、导航按钮、关闭按钮
  - [photo-progressive-view.tsx](/Users/xin/Developer/lumine/components/photo/photo-progressive-view.tsx) 的加载提示、fallback 标记、错误态
  - [photo-viewer-info-panel.tsx](/Users/xin/Developer/lumine/components/photo/viewer/photo-viewer-info-panel.tsx) 的右侧信息栏
  - [photo-viewer-thumbnail-rail.tsx](/Users/xin/Developer/lumine/components/photo/viewer/photo-viewer-thumbnail-rail.tsx) 的底部缩略条
  - [photo-viewer-hover-preview.tsx](/Users/xin/Developer/lumine/components/photo/viewer/photo-viewer-hover-preview.tsx) 的 hover 预览浮层

## 实施结果

- 首页 hover 信息层现在包含标题、基础文件信息、相册标签和拍摄参数，信息密度更完整。
- 预览组件与首页瀑布流的配色语言已统一到 Rose Pine dark 主题，不再出现局部偏白或偏纯黑的 UI 噪点。
- 参数样式和格式化逻辑完成复用，后续继续调整 hover 或信息栏时，只需要改一处共享实现。
