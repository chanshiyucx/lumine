# Viewer 组件代码质量优化方案

- 日期：2026-09-30
- 状态：已实施
- 范围：`web/components/viewer`；公共数值工具、地图中对应的限幅表达式及 OG 图片的共用尺寸计算

## 目标与约束

修正状态表达、减少重复逻辑并明确副作用边界，保持现有页面呈现与交互设计。保留布局、样式、动画参数、图片加载延迟、键盘与手势、焦点恢复、历史导航和地图实例复用行为。不增加测试，不引入状态库、Context、通用动画框架、图片缓存或新的防抖策略。

## 实施内容

1. 分享弹窗分别记录原图与预览的下载状态，保留同时下载的能力，避免相互覆盖和提前恢复按钮。未知总大小的图片下载按可见字节量去重，已知大小继续按整数百分比去重。
2. 图片响应流直接收集 TypedArray 分块，删除分块转换与多余空值判断；保留请求取消、错误处理及资源释放。删除渐进图片的重复 `loadedSource`，保留 `settledSource` 与资源 URL 对应关系。分享预览使用单一加载状态。
3. 分开管理 Escape 监听和复制提示定时器清理。过渡预览合并降级完成逻辑，Effect 内通知使用局部 Effect Event，Motion 动画回调继续使用普通函数。保留操作编号、取消标记、源元素可见性恢复及完成去重。
4. 地图尺寸观察和定位拆成两个 Effect，观察器随地图就绪和启用状态建立，定位随有效经纬度更新。保留 hydration 判断、首次位置锁存、无 GPS 隐藏以及当前 Viewer 内的实例复用。
5. 提取专用 `lib/histogram-renderer.ts`，集中 Canvas 绘制、渐变及插值函数。组件继续管理资源、尺寸和动画接续与取消；保留请求去重、缓存上限和 buffer 复用。
6. 提取 `lib/viewer-history.ts`，集中 history marker 的读取、校验、合并和删除。Controller 保留同步 `stateRef`，协调打开、选图、关闭与浏览器历史事件。
7. 几何模块只接收普通数值，第三方缩放实例的读取留在 hook。复用手势投影快照类型，移除无人消费的 `inspectorProgress` 返回值，删除只包装属性赋值的函数和重复布尔条件。`clamp` 放在公共 `web/lib/math.ts`，由手势、缩放、缩略图、直方图动画及地图共同使用，不单独建立 Viewer 内的数学工具文件；地图保留 `clampMapLatitude` 领域接口，仅复用底层计算，聚合标记尺寸也使用同一工具。
8. 保留 `hooks / lib / transition` 组织与 `viewer-controls.tsx` 的组件分组。`lib/zoomable-image.ts` 改为 `lib/zoom-geometry.ts`，删除无消费者的 `index.ts`；保持 Gallery 的显式动态导入。
9. Viewer 过渡帧与 OG 图片共同使用 `web/lib/math.ts` 中的 `fitWithinBounds`，只提取按宽高比计算容纳尺寸的纯函数。Viewer 保留原有宽高校验、居中定位和圆角处理；OG 保留布局选择与尺寸上限。保持原有运算顺序，不增加取整或校验策略。

## 保持项与排除项

- 自定义 Swiper 尺寸观察继续使用 ref：当前版本在子组件 layout effect 内同步调用 `onSwiper`，早于父组件读取实例，不存在首次观察器无法绑定的问题。
- 地图有条件地更新自身 render state，用于锁存首次符合条件的位置；不改为只能处理首次渲染的懒初始化。
- 双击识别器的懒初始化 state 与初始照片 ID state 保持原样，不机械替换为 ref。
- 保留移动端断点变化时的 hover 状态清理，避免返回桌面后恢复过期预览。
- 直方图不增加 AbortSignal、150ms 防抖或等待滑动结束的机制。共享请求的取消归属需要额外管理，延迟计算也会改变更新时机，当前没有性能测量支持这些扩展。
- `lib/shared-photo-transition.ts` 保持原位置，避免与 `transition/shared-photo-transition.tsx` 产生同 basename 的解析冲突。
- 不批量增加或删除手动 memoization。Blob 整理只去除额外的 JS 分块复制，不承诺构造过程零拷贝或具体性能增幅。
- 缩略图预览先取整再判断高度，不套用公共容纳尺寸函数。复制、下载、会话 ID、选择器转义等单一使用场景的小函数继续留在所属模块，不继续增加全局工具接口。
