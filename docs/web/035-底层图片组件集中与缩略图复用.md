# 底层图片组件集中与缩略图复用

- 状态：已实施，待人工视觉回归
- 日期：2026-09-25
- 范围：底层图片组件、缩略图调用方和 Viewer 共享转场

## 职责划分

图片展示实现统一放在 `web/components/image/`，照片业务展示保留在 `photo/`，预览交互编排保留在 `viewer/`。

```text
web/components/
  image/
    index.ts
    thumbnail-image.tsx
    thumbhash-image.tsx
    server-thumbhash-image.tsx
  photo/
    capture-setting-chip.tsx
    index.ts
  viewer/
    progressive-photo.tsx
    zoomable-image.tsx
    transition/shared-photo-transition-preview.tsx
    ...
```

- [ThumbnailImage](../../web/components/image/thumbnail-image.tsx)统一缩略图 URL、固有尺寸、适配方式、加载策略和可选 ThumbHash 占位。相册封面、地图、瀑布流、预览缩略图栏、预览底图和共享转场均复用它。
- [ThumbHashImage](../../web/components/image/thumbhash-image.tsx)负责展示 ThumbHash 或已生成的占位图 URL；解码与缓存继续由 `web/lib/thumbhash.ts` 负责。
- [ServerThumbHashImage](../../web/components/image/server-thumbhash-image.tsx)保留 `server-only` 声明和 Sharp PNG 转换。服务端调用方通过独立文件路径导入；公共 `image/index.ts` 仅导出前两个组件及缩略图数据类型，避免将服务端实现暴露给客户端导入入口。
- `photo/` 保留拍摄参数等照片业务展示，不再导出图片基础组件。删除原 `thumbhash/` 目录和旧路径，不保留兼容转发层。
- `ProgressivePhoto` 继续负责原图下载、解码、渐显交接和缩放提示；`ZoomableImage` 继续负责缩放、平移和移动端手势。共享转场继续管理定位、尺寸、裁剪、动画和源元素显隐。

不增加纯透传的 `BaseImage`。带缩放引用与加载回调的原图、社媒分享预览仍在各自场景使用 Next Image；底层集中不意味着所有图片都必须经过同一个包装。

## ThumbnailImage 使用约定

| 参数              | 默认值  | 说明                                                                       |
| ----------------- | ------- | -------------------------------------------------------------------------- |
| `photo`           | 必填    | 仅要求 `thumbHash` 和缩略图的 `url`、`width`、`height`，不依赖完整照片数据 |
| `fit`             | `cover` | `cover` 填满并裁剪，`contain` 完整显示缩略图                               |
| `loading`         | `lazy`  | 调用方决定立即加载或原生懒加载                                             |
| `showPlaceholder` | `true`  | 布尔参数；默认渲染 ThumbHash 占位图，显式关闭时不渲染、不解码              |

组件绝对定位并填满父容器，调用方必须提供定位上下文和非零尺寸，并按场景负责圆角和裁剪。缩略图采用 `alt=""`、`aria-hidden`，由外层按钮、链接或预览区域提供可访问名称。图片统一禁用原生拖拽，使用 `decoding="auto"` 和 `unoptimized`，不引入加载状态或额外淡入动画。

默认展示缩略图和 ThumbHash 占位层；不需要占位的场景显式传入 `showPlaceholder={false}`。当前只有显示与隐藏两种状态，采用布尔参数，不保留字符串枚举。瀑布流、相册封面、地图和预览缩略图栏的 7 处常规调用使用默认值，保持原有视觉效果：

```tsx
import { ThumbnailImage } from "@/components/image";

<ThumbnailImage photo={photo} loading={imageLoading} />;
```

预览底图保留完整显示、立即加载、无 ThumbHash 的行为，删除局部 `PhotoThumbnail` 定义：

```tsx
<ThumbnailImage
  photo={photo}
  fit="contain"
  loading="eager"
  showPlaceholder={false}
/>
```

共享转场使用 `loading="eager"`、`showPlaceholder={false}`和默认 `cover`，立即请求动画所需的缩略图。外层固定定位的 Motion 容器继续决定显示范围。

现有 `fit="contain"` 下的 ThumbHash 仍使用 `object-fill`，真实缩略图使用 `object-contain`。占位图一直位于缩略图下方，不会在加载完成后移除。此行为适用于现有按照片比例布局的缩略图栏；比例不匹配的容器可能在留白区域显示被拉伸的占位图，因此全屏预览显式传入 `showPlaceholder={false}` 关闭占位。本次不改变现有占位几何规则。

## 场景样式归属

移除 `scaleOnHover` 参数。瀑布流卡片和地图封面链接在各自调用处增加外层 `span`，负责原有的 1.05 倍 hover 放大、300ms 过渡及 reduced-motion 处理。占位图和缩略图一起缩放，文字与遮罩保持原位置；图片组件不感知父级 hover 状态。
