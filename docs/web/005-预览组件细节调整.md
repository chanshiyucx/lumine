# 预览组件细节调整

## 背景

上一阶段预览层已经完成了全屏布局、URL 同步和底部缩略条，但在细节上仍然和 Afilmory 有明显差距：

1. 三个区域之间仍然有外边距和圆角，不够贴边
2. 右侧信息栏不能折叠
3. 底部缩略图的 hover 悬浮预览实际上没有显示出来
4. 原图虽然有加载过程，但最终并没有稳定显示高清图，而是大多数情况下回退到了缩略图

## 问题根因

### 1. 布局仍然带有卡片式样式

上一版 [components/photo/photo-viewer.tsx](/Users/xin/Developer/lumine/components/photo/photo-viewer.tsx) 仍然保留了：

1. 外层 padding
2. 区域之间的 gap
3. 主区、右侧栏、底栏的圆角容器
4. 左上角序号 badge

这会让预览层更像一个 lightbox，而不是 Afilmory 那种贴边式查看器。

### 2. hover 预览被滚动容器裁掉

上一版的 hover 大图预览是直接渲染在横向滚动容器内部。缩略图轨道本身使用了 `overflow-x-auto`，导致悬浮预览虽然在 DOM 里存在，但视觉上被裁切掉了，所以看起来像“没有实现”。

### 3. 原图实际上是 `HEIF/HIF`

当前 manifest 中所有原图都是 `image/heif`，浏览器端无论通过：

1. `img`
2. `createImageBitmap`
3. WebGL 上传前的解码

都不能稳定直接消费这些文件。因此上一版 `PhotoProgressiveView` 在读取完原图后，实际上大多数时候还是退回了 `thumbnail.webp`，所以主图区看上去一直不是高清图。

## 已实施调整

### 1. 预览层布局改为贴边结构

当前 [components/photo/photo-viewer.tsx](/Users/xin/Developer/lumine/components/photo/photo-viewer.tsx) 已改成更接近 Afilmory 的贴边布局：

1. 外层取消 padding
2. 主图区、右侧信息区、底部缩略条之间取消 gap
3. 三个区域容器取消圆角
4. 左上角序号展示已删除
5. 底部缩略条贴底部渲染

### 2. 右侧信息栏支持折叠

预览层右上角新增了信息栏折叠按钮：

1. 桌面端可展开/收起右侧信息栏
2. 收起后主图区自动占满剩余宽度
3. 移动端仍默认不展示右侧栏

### 3. 缩略图 hover 悬浮预览已修复

当前 hover 大图预览不再挂在横向滚动容器内部，而是提升到缩略条外层壳容器上方进行绝对定位：

1. 不再受 `overflow-x-auto` 裁切
2. 桌面端 hover 时可正常显示悬浮大图
3. 悬浮图位置会根据当前缩略图在视口中的实际位置动态计算
4. 缩略图和悬浮图都会恢复彩色显示

### 4. 高清原图链路已修复

为了解决 `image/heif` 无法直接在浏览器中稳定显示的问题，这一轮对 [app/api/photos/[photoId]/route.ts](/Users/xin/Developer/lumine/app/api/photos/[photoId]/route.ts) 做了关键调整：

1. 当原图是 `HEIF/HIF` 时，服务端先拉取原图
2. 使用 macOS 原生 `sips` 在请求时转成 `JPEG`
3. 前端再从同源接口获取浏览器可解码的高清图
4. [components/photo/photo-progressive-view.tsx](/Users/xin/Developer/lumine/components/photo/photo-progressive-view.tsx) 在收到可用图像后，才进入 WebGL 或普通图片渲染路径

这样主图区终于能稳定显示高清图，而不是一直停留在缩略图兜底。

## 当前实现说明

### 1. 高清图仍然是运行时转码

本轮没有改动 manifest 生成流程，而是在请求 `/api/photos/[photoId]` 时即时转码。好处是改动范围小，能立刻解决浏览器不支持 `HEIF` 的问题；代价是首开某张图时，服务端会多一次转码成本。

### 2. 当前转码方案依赖 macOS `sips`

因为当前环境是本机 macOS 开发环境，而 `sharp/libvips` 对这批 `HIF` 压缩格式并不能稳定解码，所以本轮采用了系统原生 `sips` 作为实际可用方案。这能满足当前项目开发和本地预览，但如果后续要部署到非 macOS 环境，建议把这一步前置到素材构建流程里，预生成浏览器友好的大图版本。
