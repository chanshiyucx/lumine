# 侧边栏优化

将侧边栏做成和 Afilmory 一样的布局，就是侧边栏高度和屏幕高度一致，左侧是预览图和底部略缩图列表，侧边栏展开/收起会改变左边的宽度。

## 实施结论

已完成。

桌面端预览器现在采用真正的两栏布局：

- 左侧主区是 `flex-1`，内部由 `主预览区 + 底部略缩图 rail` 组成
- 右侧信息栏是独立的 `aside`
- 信息栏展开时占据固定宽度
- 信息栏收起时宽度归零，左侧主区自动扩展填满剩余空间

这样行为上就和 Afilmory 一致，不再是“右边额外挂一个面板”，而是标准的主区/侧边栏分栏关系。

## 具体实现

### 1. 重构 viewer 外层布局

文件：

- `components/gallery/photo-viewer.tsx`

调整为：

- 外层容器使用 `fixed inset-0`
- 桌面端使用 `lg:flex-row`
- 左侧主区使用 `flex-1 basis-0 flex-col`
- 右侧侧边栏独立渲染，不再和左侧内容混在同一列里

这一步的核心目标是保证：

- 侧边栏始终和屏幕同高
- 主图片区宽度由侧边栏是否展开直接决定
- 收起侧边栏时，左侧区域自然变宽

### 2. 信息栏改成真正的侧边栏组件

文件：

- `components/gallery/viewer/photo-viewer-info-panel.tsx`

处理方式：

- 桌面端使用 `aside`
- `aside` 高度为整屏高度
- 内部内容区单独 `overflow-y-auto`
- 通过 `width + opacity` 控制展开/收起

收起时不再直接删除组件，而是让桌面侧边栏宽度变为 `0`。这样左侧主区宽度变化更稳定，也更接近 Afilmory 的观感。

### 3. 保留移动端底部信息面板

这轮优化只让桌面端对齐 Afilmory 的“右侧侧边栏”布局。

移动端没有强行套用桌面侧边栏，而是继续使用底部信息面板：

- 打开信息时，信息内容出现在主图区和缩略图 rail 之间
- 关闭时释放纵向空间给主图区

这样可以避免在窄屏上硬塞一个右侧栏，破坏图片显示区域。

## 当前结果

现在桌面端预览器的结构是：

1. 左侧主预览区
2. 左侧底部缩略图 rail
3. 右侧全高信息栏

信息栏展开/收起会直接改变左侧可用宽度，已经符合这一阶段的目标。
