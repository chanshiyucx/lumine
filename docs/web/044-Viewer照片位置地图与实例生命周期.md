# Viewer 照片位置地图与实例生命周期

日期：2026-09-26

状态：已实施。

## 目标与展示

在 Viewer 信息面板的 Basic Information 中，Time Zone 后依次显示 Latitude、Longitude、可选 Altitude 和照片拍摄位置地图，不另设 Location Information 分区。直接使用 manifest 的 `photo.location.lat/lng`，不使用相册 map.json 的位置代替照片坐标，不修改 manifest 或 pipeline。

地图高 160px，使用与相册地图相同的 CARTO Dark Matter 样式，中心显示 Rose Pine love 紫色标记，位置点样式除颜色外对齐 Afilmory：中心点 8px，2px 白色描边、透明度 80%；波纹初始直径 12px、透明度 75%，使用默认 1 秒 animate-ping，不添加额外阴影。颜色复用站点 love 主题 token。地图不可拖动、不可滚轮缩放，不接管信息面板的滚动和移动端手势；隐藏地图版权控件，与 Afilmory 的小地图呈现一致。没有照片坐标时，整个位置区域隐藏；经纬度为 0 是合法坐标，不据此排除照片。海拔缺失只省略 Altitude 行。

本次不增加点击地图后的跳转、地名查询或相册地图对照片坐标的定位功能。

## 生命周期

采用“首次需要时创建，在当前 Viewer 内复用，退出 Viewer 时释放”的设计。不使用滚动可见性或 IntersectionObserver；即使地图还在信息面板底部，只要面板已经打开且 Viewer 可交互，就可以加载。

| 状态或操作                         | 地图行为                                                    |
| ---------------------------------- | ----------------------------------------------------------- |
| 有坐标，但信息面板尚未打开         | 不加载地图包装库和引擎，不创建地图实例                      |
| 信息面板首次打开，照片有坐标       | 按需加载地图包装库和引擎，创建一个实例                      |
| 桌面端默认打开信息面板             | Viewer 进入可交互状态后按上述规则创建                       |
| 信息面板关闭                       | 隐藏并保留实例，解除尺寸观察，暂停位置波纹                  |
| 信息面板再次打开                   | 复用实例，更新照片位置，并重新计算容器尺寸                  |
| 打开面板时切换到另一张有坐标的照片 | 使用 jumpTo 更新中心和标记位置，不重建实例、不播放移动动画  |
| 面板关闭期间切图                   | 不更新隐藏地图中心；再次打开时同步当前照片位置              |
| 切换到无坐标照片                   | 隐藏整个位置区域，保留已经创建的实例                        |
| 从无坐标照片切回有坐标照片         | 继续复用实例；面板打开时同步位置                            |
| 退出 Viewer                        | Viewer 退出动画完成后卸载，地图包装库销毁实例，清理尺寸观察 |

一个 Viewer 最多保留一个地图实例。组件不以 photo ID 或经纬度作为 React key，不因面板开关或切图重建地图。不启用地图包装库的跨卸载实例缓存，关闭 Viewer 后不保留地图。

## 组件边界

- `viewer-info-panel.tsx`：经纬度与可选海拔行追加在基本信息的 Time Zone 后，地图位于这些行下方。地图容器使用 hidden，而不条件卸载子组件，使无坐标照片也不会销毁已经创建的地图。
- `viewer-location-map.tsx`：集中处理首次创建、实例复用、中心更新、位置标记及波纹、尺寸同步和加载遮罩。通过 next/dynamic 和 ssr: false 直接延迟加载 react-map-gl/maplibre，包装库挂载时再加载 MapLibre 引擎。地图 CSS 随 Viewer 代码引入。首次创建后在当前 Viewer 内保持挂载。
- `components/map/lib/map-config.ts`：共用地图样式 URL，相册地图和位置预览使用同一配置。

移动端直达照片页时，SSR 的媒体查询默认值可能暂时按桌面布局计算。加载入口通过 useSyncExternalStore 等待客户端状态确认，避免在移动端面板初始关闭时提前创建地图。

## 尺寸与隐藏行为

重新打开面板或切回有坐标照片时调用 resize，再更新中心。面板活动时通过 ResizeObserver 观察地图容器尺寸，处理桌面宽度过渡、窗口变化和桌面/移动布局切换；关闭或隐藏时解除观察。这里的 ResizeObserver 仅用于尺寸同步，不控制滚动可见性和加载时机。

关闭面板不会取消已经开始的引擎或瓦片加载，也不清空地图缓存；它仍保留实例、内存和 WebGL 资源。只有面板活动且照片有坐标时播放位置波纹；面板关闭或切到无坐标照片时暂停。系统 prefers-reduced-motion 为 reduce 时隐藏波纹、保留中心点。地图中心通过 jumpTo 更新，不播放移动动画。这个取舍用于提高短时间反复开关面板和连续切图的流畅度，资源在 Viewer 退出时释放。

## 加载与失败

参考 Afilmory，只使用加载完成标记控制遮罩：未加载完成时显示半透明、背景模糊的 Loading map…，完成后移除遮罩。不展示 Map unavailable 或 Try again，不设置超时状态，不自动重建实例。若网络错误导致地图始终无法加载完成，遮罩会保留；坐标文字和照片预览不受影响。已完成加载的地图不会因为后续瓦片请求失败重新进入遮罩状态。

地图引擎、样式、瓦片和字形仍有独立网络与 GPU 成本。首次打开不会比一个全新 MapLibre 地图更轻；优势是避免未查看位置时加载，以及减少同一 Viewer 内的重复初始化。切换到新位置仍可能请求新瓦片。没有进行正式性能基准测试，不承诺具体加载时间、内存或帧率改善数字。

## 验证

检查移动端初始关闭不创建地图、桌面默认打开后加载、信息面板开关复用、连续切图、无坐标照片隐藏后切回复用、零坐标、加载遮罩、版权控件隐藏、波纹活动与暂停，以及退出 Viewer 后卸载。浏览器中比较地图 canvas 的 DOM backendNodeId，确认面板重开和切图前后的同一画布得到保留。

本次验证结果：

- 390×844 移动端直达有 GPS 的照片页，面板初始关闭时没有地图实例；展开后加载成功，面板滚动可以经过地图。
- 1280×900 桌面端地图正常展示；关闭再打开信息面板，canvas 的 DOM backendNodeId 保持相同，尺寸恢复正常。
- 真实照片 IMG_4692 切到无 GPS 的 DSC07124，位置区域隐藏但保留一个画布；切回仍为同一个画布。
- 隔离页面从 `(0, 0)` 切到慕尼黑坐标，地图正常显示并复用画布；卸载后地图节点数量为 0。
- 视觉优化验证：版权控件节点数为 0；波纹面板展开时 running，关闭后 paused；模拟 prefers-reduced-motion: reduce 后波纹 display 为 none。加载时只呈现 Loading map… 遮罩，完成后移除，不再有错误文案、超时逻辑或重试按钮。测试结束已恢复媒体模拟和窗口尺寸。
- 移动端关闭信息面板后保留一个地图；退出实际 Viewer 后地图节点数量为 0。退出时的包装库清理路径调用 destroy。
- 2026-09-27 合并地图文件后复验：移动端首次展开前地图节点为 0，展开后为 1；桌面关闭面板及切换到无坐标照片时暂停波纹，重开及切回有坐标照片仍保留同一个 canvas，退出后节点为 0。标记仅保留一层容器和两个 span，波纹为 12px，中心点为 8px。
- 类型检查、ESLint、Prettier、现有测试和差异检查通过。

这些验证覆盖功能和实例生命周期，不等于正式的性能基准测试。浏览器中还观察到现有直方图的一次网络读取失败；它不影响地图验证，本次未修改直方图逻辑。
