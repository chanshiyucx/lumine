# 预览信息展示

## 背景

`manifest.json` 已新增拍摄元数据，但当前预览层右侧信息栏仍然只是占位状态，无法展示：

1. 文件信息
2. 拍摄时间
3. 拍摄参数
4. 设备信息
5. 曝光相关信息

这一轮需要把右侧栏替换成真实信息面板，并尽量贴近 Afilmory 的展示结构。

## 问题根因

### 1. 数据层 schema 还没有接收新元数据

虽然 `manifest.json` 已经包含：

1. `takenAt`
2. `camera`
3. `image`

但 [lib/photos.ts](/Users/xin/Developer/lumine/lib/photos.ts) 之前的 zod schema 只解析：

1. `original`
2. `thumbnail`
3. `blurhash`
4. `title`

因此这些新增字段在 parse 后会被丢弃，客户端组件根本拿不到。

### 2. 右侧栏仍然是静态占位

[components/photo/photo-viewer.tsx](/Users/xin/Developer/lumine/components/photo/photo-viewer.tsx) 之前的右侧栏只有：

1. 标题
2. 一行简单摘要
3. 一块空的虚线占位区域

还没有任何真实元数据排版。

## 已实施调整

### 1. 扩展 `GalleryPhoto` 元数据结构

当前 [lib/photos.ts](/Users/xin/Developer/lumine/lib/photos.ts) 已新增：

1. `takenAt`
2. `camera`
3. `image`
4. `fileName`
5. `albumLabel`

同时补齐了对应的 zod schema 和 TypeScript 类型，使这些字段能够从 `manifest.json` 正常进入客户端。

### 2. 右侧信息栏改为真实信息面板

当前 [components/photo/photo-viewer.tsx](/Users/xin/Developer/lumine/components/photo/photo-viewer.tsx) 已将右侧栏改造成 4 个信息区域：

1. `Photo Info`
2. `Capture Settings`
3. `Device Info`
4. `Exposure`

其中具体展示内容包括：

1. `File Name`
2. `Format`
3. `Dimensions`
4. `File Size`
5. `Megapixels`
6. `Color Space`
7. `Taken At`
8. `Time Zone`
9. `Artist`
10. `Software`
11. `Camera`
12. `Lens`
13. `Focal Length`
14. `35mm Equivalent`
15. `Max Aperture`
16. `Exposure Program`
17. `Exposure Mode`
18. `Metering Mode`
19. `White Balance`
20. `Flash`
21. `Light Source`
22. `Scene Capture Type`
23. `Brightness`

### 3. 顶部参数区改为 Afilmory 风格 chip

参考图中的拍摄参数区，这一轮在右侧栏增加了 4 个参数 chip，用英文展示：

1. `Focal`
2. `Aperture`
3. `Shutter`
4. `ISO`

这些值优先取：

1. 焦距 chip 使用 `focalLengthIn35mm`，没有时回退到 `focalLengthMm`
2. 光圈使用 `aperture`
3. 快门使用 `shutter`
4. ISO 使用 `iso`

### 4. 缺失元数据会明确标出

当前右侧栏底部增加了 `Missing Metadata` 提示区，用于明确告诉当前素材里缺了哪些字段，而不是静默省略。

## 当前缺失字段

基于当前 `manifest.json` 的 19 张照片统计，以下字段全部缺失：

1. `Artist`
2. `Software`
3. `Light Source`
4. `Max Aperture`

说明：

1. `Time Zone` 没有单独字段，但可以从 `takenAt` 里的时区偏移直接推导，因此已正常显示
2. `File Name` 也不是独立字段，而是从 `original.url` 文件名推导

## 当前实现说明

### 1. 信息全部使用英文展示

右侧信息栏当前所有 section title、label 和缺失态文案都统一为英文，符合本轮要求。

### 2. 时间显示保留拍摄时区的本地时间

`Taken At` 没有直接使用 `new Date(...).toLocaleString()` 做本地转换，而是按原始 ISO 时间字符串中的年月日时分秒进行格式化。这样显示的是拍摄发生时的本地时间，而不是浏览器当前时区转换后的时间。
