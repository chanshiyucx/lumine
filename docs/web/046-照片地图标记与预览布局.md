# 照片地图标记与预览布局

## 目标与范围

在原有相簿地图上增加有经纬度的照片标记，并调整单个相簿和照片的预览卡片。保留已有地图控制、相簿位置配置、标记外观和聚合缩放交互，不增加独立弹窗、列表面板或测试代码。

## 数据与聚合

- 相簿仍通过 `getAlbumMapItems` 读取配置位置，但仅代表相簿内没有坐标的照片。相簿点的封面、预览格子和照片数量均从这些照片中计算；全部照片都有坐标时不生成相簿点。
- `getPhotoMapItems` 从照片集合读取有 `location` 的照片，携带名称、拍摄日期、设备、经纬度、可选海拔、缩略图和照片链接。无坐标的照片不生成照片标记。
- 相簿与照片使用独立的 Supercluster 索引，避免混合聚合。每张照片在地图上只归属一个位置：有坐标时参与照片标记或聚合，无坐标时通过相簿配置位置展示。相簿聚合仅包含仍需展示无坐标照片的相簿。
- 没有配置位置的相簿仅显示有坐标的照片；无坐标照片不会自动推断位置。
- 原来的初始相簿视野保留；没有相簿标记时使用照片计算初始视野。“显示全部”包含相簿和照片。
- 相簿聚合参数保留；照片聚合持续到地图最大缩放级别 17，使同地点照片仍可通过聚合预览展示。
- 地图绘制、聚合和视野计算使用 Mercator 可展示的纬度范围；单张照片的信息卡片保留原始经纬度。初始视野查询为空时回退到全部输入项。
- 照片与相簿通过 `kind` 明确区分；照片聚合预览直接接收照片项、数量和中心坐标，不借用单张照片的数据。

## 预览布局

| 类型         | 上半部分                           | 下半部分                                               |
| ------------ | ---------------------------------- | ------------------------------------------------------ |
| 单张照片     | 原有高度的单图封面                 | 照片名称、右侧箭头；日期、设备、经纬度、可选海拔       |
| 单个相簿     | 相簿照片的方形格子                 | 相簿名、右侧箭头；拍摄日期范围、统一设备、相簿配置坐标 |
| 多张照片聚合 | 照片的方形格子                     | 拍摄日期范围、统一设备、聚合中心坐标；无标题和导航箭头 |
| 相簿聚合     | 相簿封面的方形格子，保留相簿名字幕 | 保留原有 `n albums` 标题和布局                         |

### 方形格子规则

- 复用相簿聚合点的三列、方形、圆角和间距样式。
- 总数小于或等于 6：全部显示，不显示剩余数量格子。
- 总数大于 6：前 5 格显示照片或相簿，第 6 格显示 `+n More`，其中 `n = 总数 - 5`。例如 7 项显示 `+2 More`，24 项显示 `+19 More`。
- 单个相簿按照现有照片顺序取封面；聚合点按照现有聚合叶节点顺序取封面。
- 服务端最多提供 6 张无坐标的相簿照片作为封面；聚合预览最多显示 6 个叶节点。单个相簿的剩余数量按无坐标照片总数计算，照片聚合按聚合照片总数计算，相簿聚合按聚合相簿总数计算。
- 单个相簿按其无坐标照片、照片聚合按其全部照片计算拍摄日期范围；同一天只显示一个日期。仅当所有照片都有相同设备名称时显示设备。
- 单个相簿的数量提示格子可点击，在新标签页打开对应相簿；照片聚合和相簿聚合的数量提示格子仅展示信息。
- 六格卡片高度超过悬浮位置的可用空间时，卡片内部滚动，避免底部信息被视口裁切。

## 交互

- 单张照片和单个相簿复用现有圆形标记、悬停预览和点击固定预览。
- 点击照片名称或封面在新标签页打开照片；点击相簿名打开相簿，相簿内的封面打开对应照片。
- 相簿名与 `+n More` 仍打开完整相簿，包含有坐标和无坐标照片。地图预览的筛选不影响相簿页面内容。
- 点击聚合标记按原有方式放大地图；照片聚合卡片展示照片格子、日期范围、符合条件的设备和坐标，不显示名称与导航箭头。
- 同地点照片到达最大缩放后保持聚合，通过格子打开照片。
- 照片聚合点无法继续放大时，隐藏点外的外圈、封面数字及数字背后的黑色蒙层，保留封面与悬停格子预览；可以继续放大的聚合点仍显示外圈与数量。
- 无法继续放大的照片聚合点支持点击、触摸或键盘固定预览；再次激活或点击地图可关闭，继续复用原有悬浮卡片。
- 不增加标记角标、额外关闭按钮、URL 定位入口或独立照片列表。

## 实现位置

- `web/lib/album/map.ts`：相簿与照片地图数据，最多 6 张相簿封面。
- `web/lib/map-photo-summary.ts`：按全部相关照片汇总日期范围和统一设备。
- `web/app/map/page.tsx`、`album-map-loader.tsx`：并行读取并传递两类地图数据。
- `album-map.tsx`、`lib/album-map-selection.ts`：两类独立聚合索引，复用选中和缩放逻辑。
- `album-map-marker.tsx`：复用标记外观，分派照片和相簿预览。
- `album-preview-card.tsx`：单图封面、格子封面和截图中的下半信息布局。
- `photo-cluster-preview-card.tsx`：照片聚合的格子、日期、设备和坐标预览。
- `map-coordinates.tsx`：单个条目与照片聚合共用的坐标信息行。
- `map-preview-grid.tsx`：共用方形格子及 `+n More` 规则。
- `cluster-preview-card.tsx`：相簿聚合格子。
- `web/lib/map-config.ts`：地图样式、聚合参数、最大缩放、预览容量和 Mercator 纬度上限的共用配置。

## 验证

使用类型检查、ESLint 和浏览器检查验证实现，不新增测试代码。检查单图信息、照片聚合的日期范围和统一设备、相簿格子、聚合缩放，以及 6 格上限和剩余数量。数据检查覆盖无坐标、部分有坐标、全部有坐标及缺少相簿位置配置的情况，确保照片标记与相簿预览不重复。
