# 构建管线模块拆分

日期：2026-09-26

状态：已实施。

## 1. 目录与职责

```text
pipeline/src/
├── main.rs
├── config.rs
├── build.rs
└── build/
    ├── source.rs
    ├── metadata.rs
    ├── avif.rs
    ├── thumbnail.rs
    ├── catalog.rs
    └── storage.rs
```

| 模块 | 职责 |
| --- | --- |
| `build.rs` | 构建入口、更新判断、产物复用决策、单张照片流程、worker、限流、进度与失败处理 |
| `source.rs` | 源文件扫描、Finder 标签、文件属性、源显示尺寸与色深探测、HEIF 方向变换判断 |
| `metadata.rs` | EXIF 读取、拍摄时间、GPS、摄影参数归一化与方向标签读取 |
| `avif.rs` | 源像素解码、HEIF 高位深处理、AVIF 编码、已有 AVIF 资源信息读取 |
| `thumbnail.rs` | 系统预览、缩略图编码、缩放、已有缩略图读取、ThumbHash 与运行环境检查 |
| `catalog.rs` | manifest 和 state 数据结构、加载、资源描述生成、内容比较与 checkpoint 保存 |
| `storage.rs` | 输出路径、目录隔离、父目录创建、原子写入、受控产物清理 |

`main.rs` 继续调用 `build::run()`。配置格式、命令入口、输出路径、manifest schema、state 字段和编码参数保持原有行为。

## 2. 模块接口

| 模块 | 供 build 内部使用的主要接口 |
| --- | --- |
| source | 扫描入选文件、读取源信息、取得修改时间、判断 HEIF 类型和预览尺寸变换 |
| metadata | 读取 EXIF、提取归一化元数据、读取方向、格式化文件时间回退值 |
| avif | `decode`、`encode`、`read_existing_original` |
| thumbnail | `build`、`read_existing_thumbnail`、`mime_from_format`、`validate_runtime` |
| catalog | 加载 manifest/state、构造资源描述、保存 checkpoint |
| storage | 路径计算、目录校验、目录创建、原子写入、按预期集合清理 |

AVIF 解码与编码分别调用，使调度层能保留原有的处理计数、编码计数和全分辨率限流。`LoadedImage` 的字段对其他模块保持私有，调度层仅传递解码结果。

图片模块接收源路径、所需源信息、输出路径和各自的 `EncodingOptions`。AVIF 参数包含质量、速度和编码线程数；缩略图参数包含宽度、格式和质量。

catalog 保存接口接收 manifest 路径、state 路径、照片条目和源指纹集合。storage 清理接口接收输出根目录、两个图片目录和预期路径集合。

## 3. 调度与依赖

构建策略集中在 `build.rs`：

1. 根据源指纹判断 unchanged、changed 或 untracked。
2. 分别决定 AVIF、缩略图的复用或生成。
3. 决定 manifest 条目的完整复用、局部更新或重新提取。
4. 管理任务、内存限流、进度和成功状态。
5. 按 checkpoint 保存数据，全部成功后执行清理。

各内部模块通过以下方向协作：

- source 使用 storage 的相对路径转换。
- metadata 使用 catalog 定义的照片元数据类型。
- avif 和 thumbnail 使用源类型识别、catalog 资源描述和 storage 原子写入。
- thumbnail 额外使用 source 的显示尺寸与预览方向信息。
- catalog 使用 storage 写入 JSON。
- storage 只处理文件与路径操作。

AVIF 和缩略图通过调度层分别执行，直接从源照片生成。两个模块互不调用，构建控制规则见 [增量构建与手动重建方案](009-增量构建与手动重建方案.md)。

## 4. 类型与辅助函数归属

| 类型或实现 | 所属模块 |
| --- | --- |
| 任务、构建计划、源变化状态、worker、进度计数和限流器 | build |
| `SourceItem`、`SourceInfo` | source |
| `ExtractedMetadata`、EXIF 数值与时间转换 | metadata |
| `LoadedImage`、AVIF 编码选项、高位深采样与颜色转换 | avif |
| `BuiltThumbnail`、缩略图编码选项、缩放与 hash 计算 | thumbnail |
| `PhotoEntry`、`Asset`、`Camera`、`Location`、`ImageMetadata`、manifest/state 类型 | catalog |
| 临时文件、原子替换、路径计算与删除 | storage |

内部模块和辅助函数默认私有。供 build 及其子模块使用的接口采用 `pub(super)`；模块内部实现保持私有。各文件使用明确的 imports。
